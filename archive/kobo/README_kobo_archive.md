reference only. Do not run them: the subscription has ended, and check_kobo.py / daily_update.py overwrite
asi_history_full.json and per-ticker files.

stockanalysis_update.py, dividends = mystocks_dividend_calendar.py, ASI/sector indices = index_proxy_update.py.
